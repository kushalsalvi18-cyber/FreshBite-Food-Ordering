## About the Project
FreshBite is a simple online food ordering website developed using HTML, CSS, and JavaScript. Users can browse restaurants, view food menus, add items to the cart, complete a simulated checkout process, and track their orders. This project is completely frontend-based and does not use any backend server or database. All data is managed using JavaScript arrays.

## Features
- User Login and Registration (Simulated)
- Home page with categories and special offers
- Restaurant listing with rating filter
- Food menu with images and Veg/Non-Veg tags
- Product details popup with ingredients and nutrition information
- Shopping cart with quantity management
- Checkout with delivery time and payment method selection
- Simulated order tracking
- User account with order history
- About Us and Contact Us pages
- Responsive design for desktop and mobile devices

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

This project uses only frontend technologies with data stored in JavaScript arrays and objects.

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. No installation or backend setup is required.
